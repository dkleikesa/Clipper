# Clipper

Clipper 是一个基于 [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/) 的剪贴板历史管理器，运行在 macOS 桌面上。界面与交互参考 [Maccy](https://github.com/p0deje/Maccy)。

## 特性

- **剪贴板历史**：自动记录文本、图片、文件与富文本（HTML / RTF 等）
- **类型筛选**：按类型多选过滤（文本 / 图片 / 文件 / 富文本）
- **排序**：最后复制 / 首次复制 / 复制次数 / 内容大小，支持升序与降序
- **搜索**：精确 / 正则 / 模糊 / 混合四种模式，命中片段高亮
- **置顶**：常用条目固定在列表顶部或底部
- **预览面板**：展示内容、来源应用与元信息
- **图片识别**：自动识别图片中的文字，可一键复制
- **全局热键**：任意应用内呼出面板，快捷键可自定义
- **托盘**：菜单栏图标，⌥ 点击暂停记录
- **主题**：深色 / 浅色跟随系统

## 运行

```bash
./gradlew :desktopApp:run
```

## 使用

### 快捷键

| 操作 | 按键 |
| --- | --- |
| 呼出面板 | `⇧⌘C`（可自定义） |
| 暂停 / 恢复记录 | `⌘P`（可自定义） |
| 下一个 / 上一个 | `↓` / `↑` |
| 复制选中项 | `Enter` |
| 置顶 / 取消置顶 | `⌥P`（可自定义） |
| 删除选中项 | `⌥⌫`（可自定义） |
| 显示 / 隐藏预览 | `⌃Space`（可自定义） |
| 设置 | `⌘,` |
| 清空搜索 / 关闭 | `Esc` |

### 说明

- 自动粘贴与全局热键需要在「系统设置 → 隐私与安全性 → 辅助功能」中授权。
- 关闭窗口会隐藏到托盘，剪贴板监听继续运行。
